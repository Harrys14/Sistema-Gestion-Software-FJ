# Sistema Integral de Gestión - Software FJ

## Descripción

Aplicación desarrollada en Python para administrar clientes, servicios y reservas de la empresa ficticia Software FJ.

El proyecto aplica los principios de programación orientada a objetos y manejo avanzado de excepciones.

## Funcionalidades

- Registro y validación de clientes.
- Gestión de reservas de salas.
- Alquiler de equipos.
- Gestión de asesorías especializadas.
- Confirmación y cancelación de reservas.
- Cálculo de costos, impuestos y descuentos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante logs.

## Tecnologías

- Python 3.
- Programación orientada a objetos.
- Git y GitHub.
- Visual Studio Code.
